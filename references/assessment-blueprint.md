# Assessment blueprint

Create the blueprint before questions. Use `assets/assessment-blueprint.schema.json`. Each question names its primary/supporting skills, evidence addressed, purpose, difficulty, marks, answer type, and deterministic or rubric verification method. Question count, time, and marks must agree with the generated paper.

Default to three questions for one cluster, or four to five short questions across a broader lesson. End with reduced scaffolding or integration when appropriate. Do not show this blueprint unless requested.
