# Personalised Practice PDF — House Format v1

Normal output is A4: Questions.pdf exactly one page, Answers.pdf exactly one page, Combined.pdf exactly two pages in that order. Use a restrained navy/grey palette, readable 9.5 pt minimum body type, clear hierarchy, aligned square-bracket marks, sufficient working space, and vector diagrams adjacent to questions.

Question pages show qualification/subject, title, topic, “Original examination-style practice material”, name/date lines, time, total marks, concise instructions, numbering, marks, and an end line. They never show answers, hints, feedback, rationale, or diagnostic labels.

Answer pages use matching titles/numbering and concise complete working, equations, units, mark points, and useful alternatives. Resolve overflow by reducing blank space, tightening moderately, shortening wording, compressing working without losing steps, reducing an unspecified question count, then splitting into numbered two-page sets. Never solve overflow with unreadably small text.

Supported vector diagrams: coordinate plane/straight line, simple force or parachutist force diagram, spring schematic, line graph, and simple table. Diagram data comes only from structured JSON.
